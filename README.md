# Viral Clipper — website

Public site for Viral Clipper: what the tool does, plus its Privacy Policy
and Terms of Service.

Served via GitHub Pages from the `main` branch, root folder.

- `index.html` — landing page
- `privacy.html` — Privacy Policy
- `terms.html` — Terms of Service
- `style.css` — shared styles

Both policy links are visible in the header and footer of every page, as
required for TikTok's app review.
